# SEO и Яндекс.Директ — что сделано и что делать

Цель: сайт должен попадать в топ‑выдачи по запросам **«гофротара»**, **«гофротара
новосибирск»**, **«купить картонные коробки»**, **«коробки для переезда»**,
**«коробки для маркетплейсов»** и похожим, плюс корректно считать рекламу в
**Яндекс.Директе**.

> ⚠️ Честное предупреждение: **только внутренняя (on-page) оптимизация не гарантирует
> 1‑е место** по высокочастотным коммерческим запросам — там решает совокупность:
> техническое SEO + качество и уникальность текстов + ссылочный профиль + поведение
> пользователей + реклама. В этом репозитории сделана вся программная часть, которую
> можно сделать кодом; оставшееся — ручные шаги в Яндекс.Вебмастере и Директе (ниже).

## 0. ЧТО СДЕЛАНО В ПОСЛЕДНЕЙ ИТЕРАЦИИ (важное!)

### 0.1 Исправлен HTTP-код 404 (критично для индексации)

**Симптом:** любой несуществующий URL (`/xyz`, `/catalog/нет-такой-товар`,
`/catalog/product/нет-такой`) отдавал **HTTP 200** вместо 404. Роботы считали
такие страницы «существующими» и плодили в индексе мусорные дубли («мягкие 404») —
это одна из частых причин просадки индексации и качества сайта в целом.

**Причина:** корневые `loading.tsx` (`src/app/loading.tsx` и
`src/app/catalog/loading.tsx`) оборачивали страницы в Suspense — ответ со статусом
200 и «скелетоном» отправлялся браузеру **до** того, как страница успевала вызвать
`notFound()`. Менять статус после начала стриминга уже нельзя.

**Исправления:**
1. Удалены `src/app/loading.tsx` и `src/app/catalog/loading.tsx`
   (админский `loading.tsx` оставлен — он не влияет на публичные страницы).
2. В `src/app/[adminPath]/layout.tsx` статический `metadata` заменён на
   условный `generateMetadata`: раньше **все** 404 получали заголовок
   «Админ-панель — СибГофроТорг» (маршрут `[adminPath]` перехватывает любые
   одиночные URL). Теперь 404 отдаёт нейтральный заголовок
   «Страница не найдена · СибГофроТорг» + `noindex`.
3. 404-страница дополнена ссылками на популярные разделы (полезно людям,
   плюс внутренние ссылки для обхода).

**Проверка после деплоя:**
```bash
curl -s -o /dev/null -w "%{http_code}\n" https://sibgofrotorg.ru/test-404
# должно быть 404  (до исправления было 200)
```
Также в Яндекс.Вебмастере: «Инструменты → Анализ robots.txt / Проверка ответа сервера».

## 5. Яндекс.Директ: разбор текущего списка ключевых фраз

### Что УБРАТЬ (нецелевые — сливают бюджет и портят CTR группы)
| Фраза | Почему убрать |
|---|---|
| коробка сюрприз для шаров омск | другой город (Омск) и другой товар |
| куриный лоток коробка | лотки для яиц — не наш товар (овощные лотки — ок, «куриный» — нет) |
| сайт магазин упакофф город новосибирск | чужой бренд, нецелевой |
| гофросиб новосибирск | бренд конкурента |
| прием стрейч пленки | мы ПРОДАЁМ плёнку, а не принимаем (принимаем макулатуру) |
| купить упаковеу на большой | опечатка, 0 показов, мусор |
| новосибирск производство бумаги картоны и белых листов бумаги | не наш профиль |
| картон мебельный листовой купить | переплётный/мебельный картон ≠ гофрокартон |
| коробки 9 5 3 | бессмысленный набор цифр |
| коробка для пиццы 30 20 5 | оставить ТОЛЬКО если есть такой размер в категории «пицца» |

### Что ОСТАВИТЬ (высокая релевантность — основа кампании)
Все фразы с «новосибирск/нск», «купить», «оптом», «на заказ», «переезд»,
«маркетплейс/вб/озон», размерные («800х600х600», «600 400 400»), артикульные
(«гофроящик 717», «ящик 670»), брендовые («сибгофроторг», «ватутина 42а»).
Фразы с 0–2 показами **убирать не нужно** — они бесплатны (нет показов — нет
расходов), а редкие конверсии по ним самые дешёвые («длинный хвост»).

### Сколько ключевых фраз можно добавлять?
**Количество фраз само по себе на эффективность НЕ влияет.** В Директе ставка и
показы считаются на уровне **группы объявлений**, и «лишние» фразы не мешают друг
другу. Ограничение Яндекса — 1000 фраз на группу, но управляемо — 30–100.

**Что реально вредит:**
1. **Нецелевые фразы** (чужой город/бренд/товар) → показы без кликов → падает CTR
   группы → Директ повышает ставку → дороже каждый клик.
2. **Слишком широкие фразы без минус-слов** («коробки» — 97 281 показов: ищут и
   «коробки передач», и «подарочные коробки») → мусорные показы.

**Правильная структура (рекомендую):**
```
Кампания «Новосибирск — коробки»
├─ Группа 1: купить коробки новосибирск / коробки картонные купить … (→ /catalog)
├─ Группа 2: коробка для переезда … (→ /korobki-dlya-pereezda) ← новая посадочная!
├─ Группа 3: гофротара новосибирск … (→ /gofrotara) ← новая посадочная!
├─ Группа 4: коробки на заказ / изготовление … (→ /korobki-na-zakaz) ← новая посадочная!
├─ Группа 5: коробки для маркетплейсов / вб / озон (→ /korobki-dlya-marketplejsov)
├─ Группа 6: гофрокартон / картон листовой … (→ /catalog/gofroformat)
├─ Группа 7: стрейч, плёнка, скотч (→ /catalog/upakovochnye-materialy)
├─ Группа 8: оптом (все фразы с «оптом», другой текст объявления) (→ /catalog)
└─ Кампания «Бренд»: сибгофроторг, ватутина 42а (→ /) — копеечная, обязательно
```

**Минус-слова для всех групп (стартовый набор):**
```
передач коробка передач подарочн подарочные сюрприз свадебн торт обручальн
игрушк minecraft майнкрафт компьютер протокол магнитола ключ разъем
бесплатно своими руками руками сделать схема чертеж
омск москва спб тюмень барнаул красноярск томск кемерово
```
(плюс перекрёстная минусовка: из группы «переезд» минусуем «оптом» и наоборот,
если хотите разные объявления).

**Операторы:** `"коробки картонные купить"` (кавычки — точная фраза) для
высокочастотных, `!коробки` (восклицательный знак — точная словоформа) — для
контоля форм слова.

## 6. Как проверить результат после деплоя
- `curl -s -o /dev/null -w "%{http_code}" https://sibgofrotorg.ru/test-404` → **404**.
- `curl -s https://sibgofrotorg.ru/sitemap.xml | grep gofrotara` → новые страницы в карте.
- Вебмастер → Переобход → отправить новые страницы.
- Через 2–4 недели: Вебмастер → «Позиции» / Метрика → «Поисковые фразы».

## 7. Если сайт внезапно пропал из выдачи (диагностика)

Однодневное падение почти всегда **временная флуктуация Яндекса** при переобходе.
Проверить по порядку:
1. Сайт доступен? (с телефона, в приватном окне)
2. `robots.txt` разрешает индексацию, `Sitemap` на месте.
3. Вебмастер → Сообщения — нет ли уведомлений.
4. Главное зеркало = `https://sibgofrotorg.ru`.
5. Переобход `/` и `/catalog`.

Падение обычно возвращается само за несколько дней. Если держится дольше 2 недель —
собирать данные по позициям и проверять внешние факторы (раздел 3.3).
