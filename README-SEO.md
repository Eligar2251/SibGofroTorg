# SEO и Яндекс.Директ — что сделано и что делать

Цель: сайт должен попадать в топ‑выдачи по запросам **«гофротара»**, **«гофротара
новосибирск»**, **«купить картонные коробки»**, **«купить гофротару»** и похожим,
плюс корректно считать рекламу в **Яндекс.Директе**.

> ⚠️ Честное предупреждение: **только внутренняя (on-page) оптимизация не гарантирует
> 1‑е место** по высокочастотным коммерческим запросам — там решает совокупность:
> техническое SEO + качество и уникальность текстов + ссылочный профиль + поведение
> пользователей + реклама. В этом репозитории сделана вся программная часть, которую
> можно сделать кодом; оставшееся — ручные шаги в Яндекс.Вебмастере и Директе (ниже).

---

## 1. Что уже было в проекте (база)

- `robots.txt` (`src/app/robots.ts`) — закрыта админка, `/api/`, кабинет, заказ; есть `sitemap`.
- `sitemap.xml` (`src/app/sitemap.ts`) — главная, каталог, категории, товары, инфо‑страницы.
- Канонические URL (`canonical`), Open Graph, мета‑теги на всех публичных страницах.
- Structured Data (JSON‑LD): `LocalBusiness`, `WebSite`, `Product`, `BreadcrumbList`.
- Подтверждение прав в Яндекс.Вебмастере (мета‑тег `yandex` + запасной HTML‑файл).
- Яндекс.Метрика (загружается только после согласия на cookies, 152‑ФЗ) + цели.

## 2. Что добавлено в этой итерации (код)

### 2.2 Усилены мета‑теги

### 2.3 Яндекс.Метрика / Директ — конверсии
- Новый трекер **`click_call`** (`src/components/analytics/PhoneClickTracking.tsx`) —

  (не грузится на всём сайте).

## 3. Подключение и проверка (это важно сделать на проде)

В переменных окружения (деплой) должны быть заданы:

```env
NEXT_PUBLIC_SITE_URL=https://sibgofrotorg.ru
NEXT_PUBLIC_YANDEX_METRIKA_ID=<номер счётчика>
```

`NEXT_PUBLIC_YANDEX_METRIKA_ID` — только цифры (например `91234567`). Если не задан,
счётчик и цели просто не отправляются, сайт работает как обычно.

## 4. Ручные шаги (вне кода)

### 4.1 Яндекс.Вебмастер
1. Добавьте сайт в **webmaster.yandex.ru** (если ещё нет) — права уже подтверждены
   мета‑тегом, дополнительно ничего вставлять не надо.
2. Загрузите карту сайта: `https://sibgofrotorg.ru/sitemap.xml` → «Переиндексировать».
3. Проверьте, что робот видит новые тексты: инструмент «Проверка ответа сервера» /
   «Чистка страниц из поиска» не требуется, просто дождитесь переобхода.
4. После деплоя запросите **переобход главной и /catalog** (кнопка «Переобойти страницу»).

### 4.2 Яндекс.Метрика
1. Создайте счётчик (или проверьте, что ID совпадает с env).
2. Создайте **цели** (Метрика → Цели):
   - `order_success` — «Достижение страницы» / JavaScript‑событие (уже шлётся кодом).
   - `add_to_cart` — JavaScript‑событие.
   - `click_call` — JavaScript‑событие (звонок).
   - `inquiry_submit` — JavaScript‑событие (отправка заявки).
   - `wastepaper_submit` — JavaScript‑событие (расчёт макулатуры).
3. Включите **вебвизор** (можно позже, для анализа поведения).
4. Убедитесь, что счётчик настроен как «счётчик для целей и ретаргетинга», если планируете
   использовать данные в Директе.

### 4.3 Яндекс.Директ
1. **Привяжите Метрику к аккаунту Директа** (Директ → Настройки → Метрика) — так Директ
   видит конверсии и может оптимизироваться по ним (стратегии «Максимум конверсий» /
   «Оптимизация по звонкам»).
2. **Ссылки в объявлениях** — используйте автотегирование Яндекса (включается в
   настройках кампании), чтобы видеть переходы в Метрике по UTM.
3. **Рекламные заголовки/тексты** — продублируйте целевые запросы:
   - «Гофротара в Новосибирске — от 1 шт.» → посадочная `/`
   - «Купить картонные коробки» → посадочная `/catalog`
   - «Купить гофротару» → посадочная `/catalog`
   - «Купить гофротару оптом» → посадочная `/catalog` или категория
4. В Метрике в качестве цели конверсии для Директа укажите `order_success` (и/или
   `click_call` для звонкового сценария).
5. **Семантика**: соберите минус‑слова (объявления, запросы не по теме) и отдельные
   группы объявлений под «в розницу» и «оптом».

### 4.4 Внешние факторы (без них топ по «гофротара» не гарантирован)
- Заполните **Яндекс.Бизнес / Яндекс.Карты**: адрес, телефон, часы, фото — компания уже
  есть, стоит проверить актуальность. Это даёт органическую выдачу + пакет в Директе.
- Качественные **внешние ссылки**: отраслевые каталоги (выбер, закупки), 2ГИС, соцсети,
  обзоры на тему упаковки. Ссылки с текстом «гофротара Новосибирск» на главную.
- Обновляйте каталог и цены — Метрика показывает поведение пользователей, а регулярное
  обновление контента положительно влияет на позиции.
- Скорость сайта уже оптимизирована (см. README), проверяйте в PageSpeed после каждого
  крупного деплоя.

## 5. Как проверить результат после деплоя
- `curl -s https://sibgofrotorg.ru/ | grep seo-block` → блок на месте.
- `curl -s https://sibgofrotorg.ru/sitemap.xml` → карта отдаётся.
- Метрика → «Посетители / Отчёты» → убедиться, что цели `click_call` и `order_success`
  срабатывают.
- Поиск Яндекса: запросить переиндексацию и через 2–4 недели смотреть позиции по целям.

## 6. Если сайт внезапно пропал из выдачи (диагностика)

Однодневное падение с 1-й позиции «даже не в десятку» по коммерческому локальному
запросу почти всегда **временная флуктуация Яндекса** при переобходе, а не санкции.
Прежде чем паниковать, проверьте по порядку:

1. **Сайт доступен?** Откройте сайт с телефона (не по Wi-Fi офиса) и в приватном окне.
2. **robots.txt**: `sibgofrotorg.ru/robots.txt` — должен разрешать индексацию
   (`Allow: /`), быть правильный `Host` и `Sitemap`.
3. **sitemap.xml** — отдаётся и свежий.
4. **Вебмастер → Сообщения** — нет ли уведомлений от Яндекса.
5. **Вебмастер → Переобход страниц** — запросить переобход `/` и `/catalog`.
6. **Главное зеркало** в Вебмастере = `https://sibgofrotorg.ru` (без `www`, без `http`).
7. **Страницы в индексе** — резкого падения количества быть не должно.

Проверка «не мои ли это правки»: после любого деплоя убедиться, что на живом сайте
изменился `<title>` и появился новый контент (например `grep seo-block`). Если title
старый — правки не вышли на прод и повлиять на выдачу не могли.

Однодневное падение обычно возвращается само за несколько дней. Если держится дольше
2 недель — собирайте данные по позициям (Вебмастер → «Позиции» / трекер) и проверяйте
внешние факторы (раздел 4.4).

## 7. Если понадобятся отдельные лендинги под точные запросы

Сейчас сознательно **не** создавались новые URL (стратегия выбрана вами — усилить
существующие страницы). Если через месяц позиции не поднимутся по «купить картонные
коробки», рекомендуется добавить отдельные SEO‑страницы (например `/kartonye-korobki`
и `/gofrotara`) с уникальным контентом и FAQ — это даст больше шансов под коммерческие
низко‑ и среднечастотные запросы. В `src/components/seo/` уже есть переиспользуемые блоки
и стили, так что добавление займёт немного времени.
