## Что сделано

### Банк (приоритет — вылезал за экран)
- **bank-hero**: все колонки в одну — касса, карта ЮМ, прогноз, статистика
- **bank-pay карточки**: вертикальная раскладка, текст контрагента переносится, кнопки действий в одну строку
- **bank-toolbar**: поиск + селект + даты + сортировка — всё по столбцу
- **bank-due** (Должны нам / Мы должны): одна колонка, тексты переносятся, суммы не вылезают
- **bank-period-presets**: горизонтальный скролл пресетов периода
- **bank-cash-postings**: компактная вертикальная раскладка
- **bank-totalbar**: перенос строк, разделители скрыты

### Таблицы
- Внутренний overflow-x auto с overscroll-behavior-x contain
- Вебкит скроллбар скрыт, подсказка таблица прокручивается
- **wh-stock-table**: sticky первая колонка, скрыты артикул и цена продажи на телефоне
- **wh-report-table**: sticky первая колонка, уменьшенные padding/font
- **receipt-post-row**: горизонтальный скролл внутри

### Модалки
- Полноэкранный лист на всех типах модалок
- Sticky шапка и sticky футер с кнопками
- Safe area insets для iPhone
- 44px touch target для кнопки закрытия
- Все инпуты font-size 16px (защита от iOS zoom)

### Карточки и блоки
- Типографика clamp() для адаптивного размера шрифтов
- Текст переносится через overflow-wrap anywhere + word-break break-word
- Иконки flex-shrink 0 — не сжимаются
- Бейджи переносятся, а не вылезают

### Кнопки и контролы
- Touch target min-height 40px, стабильные padding
- Горизонтальная лента фильтров с overflow-x auto
- Сетка действий grid-template-columns repeat(2, 1fr)

### Секции
- Склад, поставки, заказы, доставки, контрагенты, попапы
- Поставки и закупки: workspace в одну колонку
- Массовый редактор, кассовая сдача
- Охрана/автозарплата, отчёты
- Перевозки: компактная форма

### Breakpoints
- 768px и меньше — основной мобильный слой
- 480px и меньше — extra small (кнопки на строку, статы в одну колонку)
- 340px и меньше — tiny phones (навигация 2 колонки, компактные шрифты)

### TypeScript
- Добавлены CSS-классы bank-hero__ym-card, bank-hero__accounts-grid, bank-hero__forecast-grid для корректного переопределения inline стилей
