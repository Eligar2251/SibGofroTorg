# Услуги: формат позиции вместо «складского товара»

## Зачем

Резка, доставка, упаковка, нанесение логотипа, аренда техники — это не коробки
на складе, а позиции с ценой, которые нужно проводить вместе с товаром:
оплатить поставщику, включить в счёт покупателю, увидеть в себестоимости и
марже. Раньше для них заводили «товар» с нулевым остатком, и он портил склад:
вечно «нет в наличии», дефицит в заказах, пустые строки в инвентаризации.

Теперь у карточки есть формат: **товар** или **услуга** (`products.is_service`).

## Что меняется для услуги

| Операция | Товар | Услуга |
|---|---|---|
| Поставка (приходный ордер) | сумма + приход на склад | сумма есть, склад не меняется |
| Заказ покупателя | списание со склада, резерв | списания и резерва нет |
| Отмена заказа / сторно поставки | возврат остатка | нечего возвращать |
| «Остатки» склада, статистика, себестоимость склада | участвует | не показывается |
| Инвентаризация (ревизия) | пересчитывается | пропускается |
| Ручная правка остатка | работает | отказ: «Услуга не имеет склада» |
| Комплектация / сборка | можно | нельзя (ошибка валидации) |
| Массовый редактор цен («Цены») | цена и остаток | цена — да, остаток — нет |
| Сайт (каталог, поиск, прайс-лист) | по `is_visible` | всегда скрыта |
| Размеры, вес, упаковка | нужны | не нужны, можно не заполнять |
| Цена, сумма, НДС, оплата поставщику — части документов | ✔ | ✔ — как у обычного товара |

Отметка «Это услуга» **не трогает** остаток и видимость уже существующего
товара: при переводе позиции в услуги `stock_qty` не обнуляется, просто склад
больше по ней не двигается. Обратно — «выключить услугу» — можно в любой момент.

## Миграция (обязательно один раз)

```
supabase/migration_product_services.sql
```

Supabase → SQL Editor → вставить файл целиком → Run. Скрипт идемпотентен,
без BEGIN/COMMIT и TEMP-таблиц, работает на пул-режиме.

**Если миграцию не выполнить, ничего не сломается**: колонки нет — флаг
просто не сохраняется (в логе `[products] Колонки is_service нет — …`),
учёт работает как раньше. Но и услуг не появится.

## Как завести услугу

1. **Склад → Поставка / Заказ** (или любой выбор позиции): внизу списка —
   «Новая позиция (товар или услуга)». Заполнить *название, цену, количество*,
   оставить галочку «Услуга» → «Создать и добавить». Позиция сразу попадёт
   в документ, а в карточках товаров появится черновик (без размеров, со
   скрытой публикацией и подсказкой в поле «Примечание»).
   Если карточка с таким названием уже есть — новая не создаётся, берётся
   существующая (тот же принцип, что у контрагентов): «Резка», «резка» и
   «РЕЗКА» — одна позиция.
2. **Товары → Новый товар** → «Настройки» → «Это услуга, а не складской товар».
3. **Товары** — фильтр «Товары и услуги» (Все / Только товары / Только услуги)
   и зелёная метка «услуга» в списке.

Черновик из пикера создаётся через `POST /api/admin/products/quick`
(только сессия админки; `is_visible = false`, `stock_qty = 0` — приход встанет
строкой поставки, а не карточкой, иначе количество посчитали бы дважды).

## Где что лежит

- `src/lib/product-service.ts` — правила: чтение флага из любой формы,
  нормализация черновика, фильтр «что двигает склад».
- `src/app/api/admin/products/quick/route.ts` — быстрое создание позиции.
- `src/components/admin/ProductPicker.tsx` — бейдж «услуга», кнопка и форма
  быстрого создания (есть во всех окнах выбора позиции; в комплектации — выключена).
- `src/lib/warehouse.ts` — `adjustStock`/`applyStockDelta`/`setWarehouseStock`/
  `applyStockRevision` пропускают услуги; `getWarehouseStock()` отдаёт `isService`.
- `src/components/admin/WarehouseManager.tsx` — услуги исключены из «Остатков»,
  статистики склада и расчёта дефицита; в позициях документов остаются.
- `src/lib/warehouse-assembly.ts` — отказ ставить услугу в комплектацию
  (`src/lib/warehouse-assembly-store.ts` при записи склада такие строки пропускает).
- `src/app/api/admin/products/[id]/route.ts` — `isService` в белом списке PATCH
  (можно перевести позицию в услуги и обратно, остаток при этом не меняется).
- `src/app/api/admin/products/bulk/route.ts` — массовое сохранение не пишет
  `stock_qty` строкам-услугам.
